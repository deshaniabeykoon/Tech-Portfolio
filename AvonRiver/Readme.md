# 📊 Avon River - Data Analysis & Engineering

This project demonstrates my ability to work as both a **Data Analyst** and **Data Engineer**.  
It includes data cleaning, transformation, exploratory data analysis (EDA), and visualization using Python.

---

## 🎯 Objectives
- Import and clean raw data  
- Explore data characteristics (summary statistics, missing values, distributions)  
- Perform transformations for analysis  
- Generate insights with visualizations  
- Summarize findings and conclusions  

---

## 🛠️ Skills Demonstrated
### 🔹 Data Analyst
- Exploratory Data Analysis (EDA)  
- Statistical summary and correlation analysis  
- Visualization with Matplotlib & Seaborn  
- Insight generation  

### 🔹 Data Engineer
- Data ingestion and preprocessing  
- Handling missing values and duplicates  
- Data transformation & schema preparation  
- Reproducible workflows
